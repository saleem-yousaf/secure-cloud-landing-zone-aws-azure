# Secure Cloud Landing Zone: AWS & Azure

**Created by Saleem Yousaf – Cloud & Cyber Security Architect**  
Website: https://www.saleemyousaf.co.uk

## Overview

This repository provides a reusable reference architecture for building secure, scalable and compliant cloud landing zones across **AWS** and **Microsoft Azure**.

It is designed for organisations that need a strong cloud foundation before deploying production workloads, private APIs, container platforms, data services and enterprise applications.

## Focus Areas

- Secure-by-design cloud architecture
- AWS and Azure landing zone foundations
- Private API patterns
- ECS / AKS workload hosting
- Identity and access governance
- Network segmentation
- Centralised logging and monitoring
- Compliance guardrails
- Infrastructure as Code foundations

## Use Cases

- AWS Landing Zone design
- Azure Landing Zone design
- Multi-cloud governance
- Secure cloud migration
- Private API hosting
- Containerised workloads
- Compliance-aligned cloud foundations
- Client cloud security assessments
