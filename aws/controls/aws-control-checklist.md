# AWS Security Control Checklist

- [ ] AWS Organizations configured
- [ ] Control Tower enabled where appropriate
- [ ] IAM Identity Center configured
- [ ] MFA enforced
- [ ] SCPs defined
- [ ] VPC private subnets configured
- [ ] VPC endpoints used for private access
- [ ] CloudTrail enabled
- [ ] AWS Config enabled
- [ ] GuardDuty enabled
- [ ] Security Hub enabled
- [ ] KMS encryption enabled
- [ ] S3 public access blocked
- [ ] Logging centralised
