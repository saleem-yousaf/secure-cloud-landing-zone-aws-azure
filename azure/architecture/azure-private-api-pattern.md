# Azure Private API Pattern

## Pattern

Private APIs are exposed through controlled internal access paths using Azure API Management, Private Endpoints and segmented VNets.

## Components

- Microsoft Entra ID
- Azure API Management
- Private Endpoints
- Virtual Network
- Azure Firewall
- Azure Key Vault
- Azure Monitor
- Log Analytics
- Microsoft Defender for Cloud
- Microsoft Sentinel

## Security Benefits

- Strong identity integration
- Reduced public exposure
- Centralised monitoring
- Policy-driven governance
- Secure cloud-native application foundation
