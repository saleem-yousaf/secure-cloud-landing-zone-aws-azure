# Azure Security Control Checklist

- [ ] Management groups configured
- [ ] Azure Policy assigned
- [ ] Microsoft Entra ID integrated
- [ ] MFA / Conditional Access enabled
- [ ] RBAC reviewed
- [ ] VNets segmented
- [ ] Private endpoints configured
- [ ] Defender for Cloud enabled
- [ ] Azure Monitor enabled
- [ ] Log Analytics configured
- [ ] Key Vault used for secrets and keys
- [ ] Public access restricted
- [ ] Sentinel integration considered
