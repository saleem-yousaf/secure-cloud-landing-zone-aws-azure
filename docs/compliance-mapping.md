# Compliance Mapping

This section maps the secure landing zone design to common control themes.

## NIST Cybersecurity Framework

| Function | Landing Zone Control |
|---|---|
| Identify | Asset inventory, tagging, ownership |
| Protect | IAM, encryption, network segmentation |
| Detect | GuardDuty, Defender for Cloud, SIEM |
| Respond | Alerting, incident response integration |
| Recover | Backup, resilience, DR design |

## CIS Controls

| CIS Control Area | Example Controls |
|---|---|
| Inventory and Control of Assets | Cloud asset inventory and tagging |
| Access Control Management | IAM, RBAC, MFA |
| Secure Configuration | AWS Config, Azure Policy |
| Audit Log Management | CloudTrail, Azure Monitor, SIEM |
| Data Protection | Encryption, KMS, Key Vault |

## ISO 27001 Themes

- Access control
- Asset management
- Cryptography
- Logging and monitoring
- Supplier and cloud service governance
- Business continuity and resilience
